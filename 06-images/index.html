image 1

quando apenas a altura ou largura é especificada a imagem é proporcionalmente redimendionada para o tamanho definido.
width: 300px

image 2

quando a altura e largura são especificadas, a imagem é redimensionada para esse tamanho podendo ser esticada caso os valores não sejam proporcionais ao tamanho original
width: 300px
height: 300px

image 3

quando a feature object-fit: contain; é usada, ela vai encaixar a imagem dentro da altura e largura definida sem esticar ou cortar nenhuma parte da image
width: 300px;
height: 300px
object-fit: contain;

image 4

quando a feature object-fit: cover; é usada, a imagem vai preencher todo o espaço definido na altura e largura sem esticar, porém pode ter partes cortadas
width: 300px;
height: 300px;
object-fit: cover;

image 5

para a imagem ter as bordas arredondadas é usada a feature border-radios: ; podendo chegar a um circulo total ao definir a border-radious como metade (ou mais) da altura e largura
width:300px;
height: 300px;
border-radios: 150px;
